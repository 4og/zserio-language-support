# Soporte de Lenguaje para zserio

Una extensión ligera de Visual Studio Code que proporciona soporte de lenguaje para archivos de esquema de [zserio](https://github.com/ndsev/zserio) (`.zs`).

## Características

- **Resaltado de Sintaxis**: Gramática integrada para archivos `.zs`.
- **Verificación de Sintaxis**: Validación de esquemas y reporte de errores en tiempo real.
- **Navegación de Código**: Soporte para *Go to Definition* (Ir a la definición) y *Peek Definition* (Vista previa de la definición).
- **Búsqueda de Símbolos**: Encuentre rápidamente símbolos del documento y del espacio de trabajo.
- **Autocompletado**: Sugerencias de completado básicas basadas en el contexto.
